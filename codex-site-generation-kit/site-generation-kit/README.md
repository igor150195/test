# Пакет внедрения генерации сайтов по референсу

Этот пакет подготовлен по итогам аудита архива `test(1).zip`. Он **не изменяет исходный проект автоматически**: это рекомендации, шаблоны процессов и стартовые Codex skills, которые можно перенести в репозиторий после проверки.

## Содержимое

- `docs/audit-and-roadmap.md` — результаты аудита и порядок внедрения.
- `docs/spacing-scale-proposal.md` — предложение по шкале отступов и сетке без массового переписывания legacy-токенов.
- `docs/reference-analysis-template.md` — шаблон разбора URL/скриншота до написания кода.
- `docs/visual-qa-checklist.md` — критерии ручной и автоматизированной проверки дизайна.
- `skills/site-from-reference/SKILL.md` — процесс создания сайта на основе URL или скриншота.
- `skills/visual-qa/SKILL.md` — процесс проверки отрендеренного сайта и исправления визуальных дефектов.
- `prompts/create-site-from-reference.md` — стартовый промпт для конкретной задачи.

## Как применить

1. Прочитайте `docs/audit-and-roadmap.md` и выполните этапы P0–P1 прежде, чем полагаться на генерацию сайта без ручного контроля.
2. Скопируйте каталоги `skills/` в `.agents/skills/` проекта. Например: `.agents/skills/site-from-reference/SKILL.md`.
3. Перенесите шаблоны `docs/` в `design-system/docs/` либо в отдельный каталог документации проекта.
4. Обновите существующий `AGENTS.md` небольшими точечными правилами — не вставляйте в него всю документацию и весь процесс целиком.
5. Настройте и проверьте доступность локального браузера/Playwright в среде Codex до того, как считать визуальную проверку автоматизированной.

## Важное ограничение аудита

Исходники, токены, документация и Sass были проверены. Прямой `npm run build` из распакованного архива завершился ошибкой `sass: Permission denied` из-за прав на файл `node_modules/.bin/sass`; прямой вызов Sass через Node успешно компилирует SCSS, но выдаёт deprecation warnings. Автоматический скриншот браузера в этой среде не удалось получить, поэтому визуальные выводы обосновываются структурой HTML/SCSS/токенов, а не просмотром пиксельного рендера.
