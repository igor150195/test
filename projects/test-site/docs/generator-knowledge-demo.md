# Демонстрация базы знаний и ручного слоя — test-site

Дата: 2026-10-16. Это ретроспективная проверка существующего проекта: она не
объявляет его прежнюю локальную реализацию новым API дизайн-системы.

## 1. Поиск подходящих решений

| Потребность | Найдено | Проверка применимости | Решение |
|---|---|---|---|
| Полная проверка длинной страницы | `KBP-0001` | Открыты pattern, QA report и артефакты четырёх viewport | Использован как candidate процесса; не копируется код |
| Карточки вакансий и карьерные media-панели | `KBP-0002` | Прочитан контракт Product Card: он предназначен для товара, цены и покупки | Отклонён: совпадение «card» не делает его применимым |
| CTA и footer | `.ds-button`, `.ds-footer` | Проверены публичные контракты компонентов | `REUSE` там, где разметка соответствует контракту |
| Переключаемые направления с фото | нет `verified`/`approved` pattern | Проверены Form, Button, Product Card и блоки | `EXTEND`, описан в [gap report](design-system-gap-report.md) |

## 2. Кандидат в знания

Создан [KBP-0001](../../../design-system/docs/generation/knowledge/patterns/kbp-0001-full-site-capture-matrix.md): минимальный повторяемый workflow для полного набора screenshot. У него статус `candidate`, потому что подтверждение есть только на одном независимом проекте. Он не становится компонентом и не даёт права расширять CSS API.

## 3. Ручные изменения владельца

Существующий `css/custom.css` уже содержит основную локальную реализацию,
поэтому не был переписан. Для совместимого ручного слоя добавлены:

- исходник [styles/custom.scss](../styles/custom.scss);
- результат [css/custom-overrides.css](../css/custom-overrides.css);
- последнее подключение в [index.html](../index.html).

Команда `npm run project:styles -- build test-site css/custom-overrides.css`
скомпилировала файл. Повторная инициализация проверяется изолированным тестом
`npm run test:project-styles`: владелец добавляет комментарий и правило, после
повторного `ensureCustomScss()` файл сравнивается byte-for-byte по хвосту и
собирается в CSS.

## 4. Проверка подключения

Реальный рендер `http://127.0.0.1:4173/projects/test-site/` открыт после
изменения. Браузер подтвердил последовательность шести stylesheet, где
`custom-overrides.css` последний; overflow на desktop-снимке отсутствует.
Скриншот: `../artifacts/custom-style-2026-10-16/desktop-1440x900.png`.

Поскольку ручной SCSS пока содержит только сохраняемый комментарий, эта
проверка подтверждает отсутствие визуальной регрессии от подключения, а не
новое стилевое поведение.
