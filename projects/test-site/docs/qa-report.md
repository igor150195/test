Дата: 2026-10-16. Проверены реальный локальный рендер `http://127.0.0.1:4173/projects/test-site/` и доступный публичный референс `https://hr.tutu.ru/`. Единственный внутренний маршрут проекта — `index.html`.

4. Преимущества расширены с шести до девяти карточек.
5. Устранены слишком узкий заголовок hero и перекрытие текста самолётом в блоке форматов работы.

## Технические результаты финального прогона

Исходные данные: `../artifacts/visual-qa/reference-restoration-2026-10-16/final-matrix/project-pass-3/results.json`.

| Проверка | 1920 | 1440 | 768 | 390 |
|---|---:|---:|---:|---:|
| Ответ страницы | 200 | 200 | 200 | 200 |
| Сломанные изображения | 0 | 0 | 0 | 0 |
| Ошибки консоли | 0 | 0 | 0 | 0 |
| Горизонтальное переполнение | нет | нет | нет | нет |
| Видео загружено и играет | да (`readyState: 4`) | да | да | да |

Playwright одновременно записал один `net::ERR_ABORTED` для MP4 в каждом прогоне. Это не сломанный ресурс: `currentSrc` указывает на локальный MP4, `readyState` равен 4 и `paused` — false. Причина, вероятно, в отмене параллельного запроса браузером во время получения скриншота; она остаётся отмеченной как техническая особенность, а не скрыта как «чистый» сетевой прогон.

`npm run build` и `npm run check:sass` прошли успешно. В выводе остаются предсуществующие предупреждения Sass о legacy `@import` и slash-division в `design-system/mixins/_shop.scss`.

## Оставшиеся расхождения и ограничения

- Hero оригинала — динамическое видео, поэтому снимки могут показать разные кадры, хотя используется тот же локальный ролик.
- Оригинальные блоки «от первого лица» и вакансии работают как интерактивные внешние видео/карусели. Проект сохраняет их визуальную структуру и контент, но не добавляет сторонний видеоплеер или JS-карусель.
- Точный фирменный веб-шрифт оригинала не внедрён: проект использует публичный стек дизайн-системы.
- Полноразмерный снимок, приложенный пользователем, не находится в репозитории по указанному пути `references/hr-tutu-reference-full.png`; проверка опиралась на приложенное изображение и live reference.
