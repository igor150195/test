## Фактические проверки

- `npm run build` — пройден.
- `npm run check:sass` — пройден.
- Оба запуска выводят существующие предупреждения legacy Sass: `@import` и slash-division. Новых Sass-ошибок нет.
- Локальный маршрут `/projects/test-site/` возвращает HTTP 200 на 1920×1080, 1440×900, 768×1024 и 390×844.
- На всех размерах: нет console errors, HTTP >= 400, сломанных `<img>` и горизонтального overflow.
- Статический сервер подтверждённо обрабатывает `Range: bytes=0-99` для MP4 ответом `206`, `Content-Type: video/mp4` и корректным `Content-Range`.
