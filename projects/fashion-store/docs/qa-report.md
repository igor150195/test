# Visual QA: fashion-store

Дата: 2026-10-15. Проверка выполнена по адресу
`http://127.0.0.1:4173/projects/fashion-store/` во встроенном браузере.
Живой референс `https://clothing-shop.oml.ru/` был доступен и сравнен с
локальной страницей на desktop.

## Снимки

| Вид | Размер | Статус | Путь |
| --- | --- | --- | --- |
| Локальная страница, desktop | 1440 × 900 | Захвачен и визуально проверен, финальный проход | Браузер вернул изображение в диалог; API не поддерживает экспорт PNG в рабочую папку. |
| Референс, desktop | 1440 × 900 | Захвачен и сопоставлен с локальной страницей | То же ограничение API. |
| Локальная страница, mobile | 390 × 844 | Захвачен и визуально проверен после первого цикла исправлений | То же ограничение API. |
| Локальный каталог, mobile | 390 × 844, якорь `#new` | Захвачен и проверен: карточки не перекрываются | То же ограничение API. |

Файловые пути к PNG намеренно не вымышлены. Для воспроизводимых файловых
артефактов проекту требуется browser runner с поддержкой записи скриншотов.

## Сравнение и исправления

1. **Desktop hero:** локальный заголовок переносился на две строки, тогда как
   в референсе он расположен в одну. Убрана принудительная строка в HTML,
   скорректированы ширина текстового контейнера и desktop-типографика.
2. **Desktop header:** навигация находилась слишком далеко справа. Колонка
   логотипа ограничена локально, навигация теперь ближе к положению референса.
3. **Mobile header:** поле поиска делало верхнюю часть заметно выше референса.
   Оно скрыто только для `max-width: 700px`; поиск не заявлен как рабочая
   функция сайта.
4. **Mobile hero:** текст соприкасался с моделью. Добавлены локальный
   градиент, отдельный stacking context и компактная mobile-типографика.
5. **Mobile каталог:** карточки проверены в отдельном scroll region; одна
   колонка, изображения, цены и CTA не конфликтуют по ширине.

## Нерешённые ограничения

- Бренд и текстовый логотип намеренно отличаются от демонстрационного
  «Название компании» в референсе.
- Карусель hero, корзина, поиск и избранное остаются статическими: нет
  прикладной логики в задаче.
- Нижние разделы исходного сайта нельзя сравнить пиксель-в-пиксель: на
  странице референса поверх контента отображается панель демо-платформы.
- Изображения загружаются с домена референса и не имеют локального fallback.
