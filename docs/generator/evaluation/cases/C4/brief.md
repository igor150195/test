# C4 generation brief — pilot-1

Derived from `projects/pilot-1/docs/reference-analysis.md` and the explicit
scope approval dated 2026-10-22.

- Build one static English fashion-commerce demo home page.
- Use only the neutral DS Header, Product Card and Footer compositions plus
  their documented components.
- Include a static demo hero and one static New Arrivals product grid.
- Use only local `rights: placeholder` image assets and visible demo labels;
  no reference brand, text, images, product claims, commerce flows, carousel or
  tabs.
- Omit utility/primary navigation, promo cards, lookbook, reviews, blog and
  social feed because those needs remain deferred Design System gaps.
