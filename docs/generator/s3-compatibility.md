# S3 compatibility

## Confirmed

Целевой движок S3 — scssphp. Проверено, что точки входа дизайн-системы
собираются на scssphp версий 1.5.0–1.13.0. Версия 1.4.0 не подходит: она
падает на plain CSS с custom properties в токенах.

Поэтому проектные SCSS для S3 используют только `@import`. `@use`,
`@forward` и обращения через `sass:*` не являются частью совместимого
контракта. `npm run check:sass-compat` проверяет это ограничение в
`projects/*/styles/*.scss` и `design-system/templates/project/styles/`.

Предупреждения Dart Sass об устаревших `@import` и `slash-div` сознательно
не исправляются: миграция на module syntax отменена, пока S3 остаётся на
scssphp.

## Not verified

- Побайтная или визуальная идентичность вывода scssphp и Dart Sass.
- Фактическая версия scssphp в окружении конкретной S3-платформы.
- Структура файлов, точки входа и правила подключения SCSS на этой платформе.

Перед публикацией на S3 владелец должен подтвердить эти условия на целевой
платформе; локальная Dart Sass-сборка не служит таким подтверждением.
