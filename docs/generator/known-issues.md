# Известные ограничения генератора

## Visual regression: мягкий порог сравнения скрывает цветовые изменения

**Статус:** подтверждено 2026-10-20.

`visual:qa` использует Playwright `toHaveScreenshot` с внутренним
`pixelmatch`-порогом `threshold: 0.2`. При этом пороге небольшие, но
визуально заметные изменения цветов могут давать ноль учитываемых пикселей и
не приводить к падению теста. Это не является доказательством отсутствия
визуальной регрессии.

До отдельного согласования изменения порога проверка должна сопровождаться
сравнением карт diff с `threshold: 0` для изменений тем, цветов, границ и
состояний компонентов. Baseline автоматически не обновлять.

## Контраст старой цены в house-store

**Статус:** подтверждено 2026-10-21; не исправляется в шаге Price.

В `projects/house-store/index.html` старая цена
`<data value="12900">` использует `.ds-price__old`. Цепочка токенов:

```text
.ds-price__old -> color: var(--old_price_color)
  -> --old_price_color: var(--on_bg_main_5)
  -> house-store --on_bg_main_5: rgba(32, 33, 31, .5)
  -> --bg_main: #F2F0E9
```

После композиции полупрозрачного foreground с поверхностью фактический цвет
примерно `#898986`; его контраст с `#F2F0E9` — около **3.0:1**, поэтому Axe
сообщает `color-contrast` для `data[value="12900"]`. Это отдельный token
`--old_price_color`; изменение `--price_sale_text_color` к нему не относится.
Исправление требует отдельного решения о контрасте старой цены во всех
проектах.
