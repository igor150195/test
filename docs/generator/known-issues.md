# Известные ограничения генератора

## Visual regression: мягкий порог сравнения скрывает цветовые изменения

**Статус:** подтверждено 2026-10-20.

`visual:qa` использует Playwright `toHaveScreenshot` с внутренним
`pixelmatch`-порогом `threshold: 0.2`. При этом пороге небольшие, но
визуально заметные изменения цветов могут давать ноль учитываемых пикселей и
не приводить к падению теста. Это не является доказательством отсутствия
визуальной регрессии.

До отдельного согласования изменения порога проверка должна сопровождаться
сравнением карт diff с `threshold: 0` для изменений тем, цветов, границ и
состояний компонентов. Baseline автоматически не обновлять.
