# Button

Нейтральный компонент кнопки. Его публичный класс — `.ds-button`; он не
использует Shop2, Remodal, `gr-*`, `.js-selected` или legacy SCSS-mixin.

## HTML-контракт

Для действия используйте нативный `button` с явно заданным `type`:

```html
<button class="ds-button ds-button--primary" type="button">
    Сохранить
</button>
```

Для навигации используйте ссылку с теми же классами:

```html
<a class="ds-button ds-button--secondary" href="/catalog/">
    Перейти в каталог
</a>
```

Добавляйте ровно один модификатор варианта. Если модификатор отсутствует,
базовый класс не задаёт цветовую схему.

| Модификатор | Назначение |
|---|---|
| `.ds-button--primary` | Основное действие. |
| `.ds-button--secondary` | Второстепенное действие на primary-tint фоне. |
| `.ds-button--ghost` | Ненавязчивое действие без базового фона. |
| `.ds-button--accent` | Действие на accent-цвете. |
| `.ds-button--white` | Светлая кнопка с границей. |

## Состояния и доступность

- Hover и active применяются только к интерактивной кнопке.
- Клавиатурный фокус оформляется через `:focus-visible`; цвет кольца можно
  переопределить переменной `--focus_ring_color`, а контур Core —
  `--focus_color`.
- Для нативной кнопки используйте `disabled`:

```html
<button class="ds-button ds-button--primary" type="button" disabled>
    Недоступно
</button>
```

- Для ссылки нельзя использовать `disabled`. Укажите `aria-disabled="true"`
  и обеспечьте в прикладном коде запрет перехода; этот атрибут меняет только
  визуальное состояние компонента.

Иконки, загрузчики, размеры и составные варианты не входят в первый контракт
компонента.
