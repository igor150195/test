# Knowledge inbox

Inbox — изолированное место для предложений после принятого проекта. Каждая
запись имеет статус `candidate` и проверяется `npm run kb:validate -- --inbox`.
Эти записи не входят в активные `patterns/`, сгенерированные `registry.yml`,
`index.json` или стандартный `kb:search`.

Храните запись как `kbp-0000-*.md`, а её текстовые evidence-снимки — в
`evidence/<id>/`. Не копируйте PNG из QA artifacts: они игнорируются Git и не
являются устойчивым доказательством для базы знаний.
