- Управление: стрелки, пагинация, carousel state или отсутствие; отмечать только наблюдаемое

Для каждого существенного элемента назначить статус из
[Design System First](design-system-first.md). До заполнения изучить

| Элемент референса | Проверенные файлы/API | Статус: REUSE / COMPOSE / EXTEND / BLOCKED | Обоснование | Разрешённое действие |

| Card | | | | |

`EXTEND` и `BLOCKED` останавливают реализацию затронутой секции. До начала
кода создать `design-system-gap-report.md`, описать нужное системное изменение
и дождаться явного одобрения. Локальный alias, самодельный компонент или
упрощённая декоративная замена не переводят такой элемент в `REUSE` или
`COMPOSE`.
